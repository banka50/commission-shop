# Комиссионный магазин

Веб-приложение для автоматизации работы комиссионного магазина.
Стек: Python, Flask, SQLAlchemy, Bootstrap 4, DataTables, Chart.js.

---

## Установка и запуск

### Зависимости

```bash
pip install -r requirements.txt
```

### Переменные окружения

Создайте файл `.env` в корне проекта (или заполните `config.toml`):

| Переменная       | Описание                                      | Пример значения             |
|------------------|-----------------------------------------------|-----------------------------|
| `DB_ENGINE`      | СУБД: `postgresql`, `sqlite`, `mysql`         | `postgresql`                |
| `DB_USER`        | Пользователь БД                               | `postgres`                  |
| `DB_PASSWORD`    | Пароль                                        | `secret`                    |
| `DB_HOST`        | Хост                                          | `localhost`                 |
| `DB_PORT`        | Порт                                          | `5432`                      |
| `DB_NAME`        | Имя базы данных                               | `commission_shop`           |
| `SECRET_KEY`     | Секретный ключ Flask для сессий               | `changeme`                  |
| `UPLOAD_FOLDER`  | Путь для хранения фотографий товаров          | `src/static/uploads`        |

По умолчанию используется PostgreSQL. Для SQLite достаточно указать `DB_ENGINE=sqlite`.

### Конфигурационный файл (опционально)

Создайте `config.toml` рядом с `app.py`:

```toml
[database]
engine   = "postgresql"
user     = "postgres"
password = "secret"
host     = "localhost"
port     = 5432
name     = "commission_shop"

[app]
secret_key = "changeme"
```

### Запуск

```bash
cd src
python app.py
```

Приложение будет доступно по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000).

## Workflow

### 1. Первоначальная настройка

1. Откройте раздел **Категории** → добавьте категории товаров (например: «Одежда», «Электроника»).
2. Откройте раздел **Комитенты** → добавьте комитента (ФИО, контакты, ИНН, паспорт).

### 2. Приёмка товара от комитента

1. Перейдите в **Акты приёма** → **Добавить акт**.
2. Укажите номер акта, дату, комитента, процент комиссии и минимальную сумму комиссии.
3. На странице акта нажмите **Добавить товар** — откроется форма с уже выбранным актом.
4. Заполните карточку товара: наименование, описание, цену, категорию, сроки реализации.
5. Загрузите фотографии (можно несколько).
6. Сохраните — товар получит статус **«На витрине»**.

### 3. Управление товарами

- На странице товара можно загружать и удалять фотографии (удаление происходит после сохранения формы).
- В карточке товара отображается текущий **статус** и кнопка действия:
  - «На витрине» → **Оформить продажу**
  - «Продан» → **Оформить возврат от покупателя**
  - «Возвращён комитенту» → действия недоступны

### 4. Продажа товара

1. Откройте карточку товара → **Оформить продажу**.
2. Укажите дату, цену продажи, комиссию, статус (`Ожидает оплаты` или `Оплачено`).
3. После сохранения товар получит статус **«Продан»**.

### 5. Возврат от покупателя

1. Откройте карточку проданного товара → **Оформить возврат от покупателя**.
2. Создайте продажу со статусом **«Возврат от покупателя»**.
3. Товар вернётся в статус **«На витрине»** и снова доступен для продажи.

### 6. Возврат товара комитенту

1. Перейдите в **Акты возврата** → **Создать акт**.
2. Укажите номер, дату, комитента и нажмите **Создать акт** — система перейдёт к странице редактирования акта.
3. В разделе **«Товары в акте»** выберите нужный товар из выпадающего списка и нажмите **Добавить**.
   - В списке отображаются только товары выбранного комитента со статусом «На витрине» или «Возвращён комитенту» другим актом.
4. Товар переходит в статус **«Возвращён комитенту»** и привязывается к акту.
5. Чтобы убрать товар из акта — нажмите **Убрать** в строке товара; товар вернётся в «На витрине».
6. Реквизиты акта (номер, дата, примечание) можно изменить прямо на этой же странице.
7. Для перехода в режим просмотра (без редактирования) нажмите **Просмотр**.

### 7. Отчёт по продажам

1. Перейдите в **Отчёты по продажам** → **Сформировать отчёт**.
2. Укажите номер, дату формирования и период (с — по).
3. Нажмите **Создать** — система автоматически включит все продажи со статусами **«Оплачено»** и **«Возврат от покупателя»** за указанный период.
   - Возвраты учитываются с отрицательными суммами, что корректно уменьшает итоговую выручку.
4. Отчёт сохраняется как snapshot: данные зафиксированы на момент создания и не изменятся при последующих правках продаж.
5. На странице отчёта доступны:
   - сводные итоги (выручка / комиссия / к выплате),
   - детализация по строкам с категориями, комитентами и суммами,
   - **диаграмма выручки по категориям**,
   - **кнопка «Печать»** (навигация и элементы управления скрываются автоматически).
6. Готовый отчёт можно редактировать (изменить номер, даты, описание) или удалить.

### 8. Дашборд

Раздел **Дашборд** открывает оперативную картину работы магазина:

- **KPI текущего месяца** — выручка, комиссия и количество продаж с учётом возвратов.
- **Распределение товаров по статусам** — круговая диаграмма («На витрине» / «Продан» / «Возвращён комитенту»).
- **Выручка по категориям** за текущий месяц — горизонтальная гистограмма.
- **Тренд выручки и комиссии** за последние 12 месяцев — линейный график.
- **Предупреждения** — таблицы товаров с истекающим сроком реализации (≤ 30 дней) и уже просроченных.

## Структура данных

### `Consignor` — Комитент

| Поле            | Тип           | Описание                        |
|-----------------|---------------|---------------------------------|
| `id`            | Integer PK    | Уникальный идентификатор        |
| `last_name`     | String(50)    | Фамилия                         |
| `first_name`    | String(50)    | Имя                             |
| `middle_name`   | String(50)    | Отчество (необязательно)        |
| `email`         | String(100)   | Электронная почта (уникальный)  |
| `phone_number`  | String(20)    | Номер телефона (уникальный)     |
| `passport_data` | String(50)    | Паспортные данные (уникальный)  |
| `inn`           | String(12)    | ИНН (уникальный)                |

### `ConsignorReport` — Акт приёма товара

| Поле             | Тип           | Описание                                           |
|------------------|---------------|----------------------------------------------------|
| `id`             | Integer PK    | Уникальный идентификатор                           |
| `number`         | String(50)    | Номер акта (уникальный)                            |
| `date`           | Date          | Дата акта                                          |
| `description`    | String(200)   | Описание                                           |
| `consignor_id`   | FK → Consignor | Комитент                                          |
| `commission_pct` | Numeric(5,2)  | Процент комиссии магазина (например, 20.00)        |
| `commission_min` | Numeric(10,2) | Минимальная сумма комиссии в рублях                |

### `ConsignorReturn` — Акт возврата комитенту

| Поле           | Тип           | Описание                       |
|----------------|---------------|--------------------------------|
| `id`           | Integer PK    | Уникальный идентификатор       |
| `number`       | String(50)    | Номер акта (уникальный)        |
| `date`         | Date          | Дата акта                      |
| `description`  | String(200)   | Примечание (необязательно)     |
| `consignor_id` | FK → Consignor | Комитент                      |

### `Category` — Категория товара

| Поле          | Тип         | Описание                     |
|---------------|-------------|------------------------------|
| `id`          | Integer PK  | Уникальный идентификатор     |
| `name`        | String(100) | Название (уникальное)        |
| `description` | String(200) | Описание (необязательно)     |

### `Product` — Товар

| Поле                  | Тип                | Описание                                      |
|-----------------------|--------------------|-----------------------------------------------|
| `id`                  | Integer PK         | Уникальный идентификатор                      |
| `product_name`        | String(100)        | Наименование товара                           |
| `description`         | String(500)        | Описание (необязательно)                      |
| `delivery_date`       | Date               | Дата приёмки в магазин                        |
| `expiry_date`         | Date               | Срок реализации                               |
| `price`               | Numeric(10,2)      | Цена приёмки (изначальная)                    |
| `status`              | Enum               | Текущий статус товара (см. ниже)              |
| `category_id`         | FK → Category      | Категория (необязательно)                     |
| `consignor_report_id` | FK → ConsignorReport | Акт приёма, по которому поступил товар      |
| `consignor_return_id` | FK → ConsignorReturn | Акт возврата (заполняется при возврате)     |

### `ProductImage` — Фотография товара

| Поле         | Тип         | Описание                                              |
|--------------|-------------|-------------------------------------------------------|
| `id`         | Integer PK  | Уникальный идентификатор                              |
| `filename`   | String(255) | Имя файла на файловой системе (в `UPLOAD_FOLDER`)     |
| `product_id` | FK → Product | Товар                                                |

### `Sale` — Продажа

| Поле         | Тип           | Описание                          |
|--------------|---------------|-----------------------------------|
| `id`         | Integer PK    | Уникальный идентификатор          |
| `sale_date`  | Date          | Дата продажи                      |
| `sale_price` | Numeric(10,2) | Фактическая цена продажи          |
| `commission` | Numeric(10,2) | Сумма комиссии магазина           |
| `status`     | Enum          | Статус продажи (см. ниже)         |
| `product_id` | FK → Product  | Проданный товар                   |

### `SalesReport` — Отчёт по продажам

| Поле               | Тип           | Описание                                         |
|--------------------|---------------|--------------------------------------------------|
| `id`               | Integer PK    | Уникальный идентификатор                         |
| `number`           | String(50)    | Номер отчёта (уникальный)                        |
| `date`             | Date          | Дата формирования                                |
| `date_from`        | Date          | Начало отчётного периода                         |
| `date_to`          | Date          | Конец отчётного периода                          |
| `description`      | String(200)   | Примечание (необязательно)                       |
| `total_revenue`    | Numeric(10,2) | Итоговая выручка за период                       |
| `total_commission` | Numeric(10,2) | Итоговая комиссия магазина                       |
| `total_payable`    | Numeric(10,2) | Итого к выплате комитентам                       |

### `SalesReportLine` — Строка отчёта

| Поле             | Тип           | Описание                                                       |
|------------------|---------------|----------------------------------------------------------------|
| `id`             | Integer PK    | Уникальный идентификатор                                       |
| `report_id`      | FK → SalesReport | Отчёт                                                       |
| `sale_id`        | FK → Sale     | Ссылка на продажу (может быть NULL, если продажа удалена)      |
| `sale_date`      | Date          | Дата продажи (snapshot)                                        |
| `product_name`   | String(100)   | Наименование товара (snapshot)                                 |
| `category_name`  | String(100)   | Категория (snapshot, может быть NULL)                          |
| `consignor_name` | String(150)   | ФИО комитента (snapshot)                                       |
| `sale_price`     | Numeric(10,2) | Цена продажи (snapshot)                                        |
| `commission`     | Numeric(10,2) | Комиссия магазина (snapshot)                                   |
| `payable`        | Numeric(10,2) | К выплате комитенту = цена − комиссия (snapshot)               |

### Статусы товара

| Статус                  | Описание                                           |
|-------------------------|----------------------------------------------------|
| `На витрине`            | Доступен для продажи                               |
| `Продан`                | Оплачен покупателем                                |
| `Возвращён комитенту`   | Включён в акт возврата и передан обратно комитенту |

### Статусы продажи

| Статус                    | Описание                             |
|---------------------------|--------------------------------------|
| `Ожидает оплаты`          | Продажа создана, оплата не получена  |
| `Оплачено`                | Оплата получена                      |
| `Возврат от покупателя`   | Покупатель вернул товар              |
